## Objective

Close a concrete non-overwrite race in backup and restore publication: POSIX `os.replace(stage, final_dir)` can replace an empty directory created after the preflight existence check. Promotion must be atomic and no-replace.

## Changes

- Added `_rename_directory_noreplace`.
- Linux uses libc `renameat2(..., RENAME_NOREPLACE)`; Windows uses `os.rename`, which refuses an existing destination.
- Unsupported POSIX platforms or Linux environments without `renameat2` fail closed instead of falling back to replacement semantics.
- Both complete-backup and complete-restore promotion paths now use the helper. Failure archival remains separate.
- Added a two-thread destination-race regression: exactly one stage can win; the loser remains intact.
- Added an empty-existing-destination regression, specifically covering the case that ordinary POSIX directory replacement could otherwise replace.
