## Objective

Fix the backup-manifest digest regression on PR #28 without weakening integrity checks or changing original source assets.

## Root cause

create_source_backup and inventory generation compute the canonical digest with actual NUL and newline bytes. The new restore-side reconstruction accidentally used the two-character literal sequences backslash-zero and backslash-n. This made valid backups fail aggregate verification before the destination safety check, causing:
- the normal restore test to error;
- the CLI backup/restore round-trip to fail;
- the existing-destination test to receive the wrong earlier error.

The failure was deterministic and was not a Godot or FFmpeg failure.

## Changes

- On PR #28 branch production/backup-manifest-integrity-2026-11-18, changed the restore digest delimiters to match inventory generation exactly:
  - aggregate.update(b"\\0") → aggregate.update(b"\0")
  - aggregate.update(b"\\n") → aggregate.update(b"\n")
