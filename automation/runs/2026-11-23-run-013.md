## Objective

Extend atomic no-replace publication to failed backup/restore staging archives. A competing process can create an empty `FAILED-*` or `INTERRUPTED-*` directory after the preflight name check; `os.replace` could replace that empty directory and misreport where the incomplete stage was preserved.

## Changes

- Backup failure archival now uses `_rename_directory_noreplace` rather than `os.replace`.
- Restore failure/interruption archival uses the same no-replace primitive.
- Both exception handlers catch an archival `BackupError` as well as `OSError`, preserving the original copy/restore failure and leaving the staging directory intact when archival cannot safely complete.
- Error messages now report the staging path when the stage still exists, rather than incorrectly reporting a competing archive destination merely because that destination exists.
- Added two race regressions. Each creates a competing empty archive destination after preflight, forces the no-replace publication to refuse it, and asserts that the original stage and failure report remain intact, the competing destination remains empty, and the surfaced error names the surviving stage.
