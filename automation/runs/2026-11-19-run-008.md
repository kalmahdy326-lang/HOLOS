## Objective

Preserve an incomplete restore as actionable evidence when a catchable hard interruption occurs, and prove that retrying from the original verified backup into a new destination is safe.

## Changes

- `restore_source_backup` now catches `BaseException` only to preserve staging evidence before re-raising non-`Exception` interruptions such as `KeyboardInterrupt` and `SystemExit`.
- A simulated interruption writes `restore-interruption.json` with status, the verified files copied before interruption, the error, and explicit retry guidance.
- The partial stage is atomically renamed to an `INTERRUPTED-*` directory in the same restore filesystem. It is never promoted to a complete restore or deleted automatically.
- Ordinary exceptions retain the existing `FAILED-*` preservation and `BackupError` behavior.
- Added a regression test that interrupts after one verified file copy, checks the interruption record and preserved stage, then retries from the unchanged backup into a new destination.
