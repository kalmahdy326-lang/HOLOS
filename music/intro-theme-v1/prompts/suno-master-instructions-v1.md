# Master generation brief — HOLOS intro theme

Project author: Khaled AL-MAHDY
Title: What's Holding the Whole?
Target: approximately 54 seconds; title-sequence cue.

## Creative objective
Make a catchy, immediately identifiable theme for an adult animated science-fiction mystery. The opening five seconds should sound like a huge space opera, then cut sharply into quirky alternative rock. The song should make the premise understandable without becoming a plot synopsis or novelty song.

## Canonical cast context
- Khaled: senior relational physicist; controlled, sceptical, evidence-driven, dryly sarcastic. Visual action: checking data and preserving the record.
- Kevin: junior systems investigator; clever, impulsive, funny, insecure and rebellious. Visual action: reaching for the lever he should not touch.
- ORBIT: station AI; brutally literal, calm and deadpan. Represent through interfaces and diagnostics, not a humanoid robot.
- Moon/Lunar Interface: unresolved voice through connected lunar observation systems.
- Unknown Voice/Fourth Signal: separate from lunar regions A/B/C; nature unknown.

The singer is an external narrator, not a cast member. No individual character dialogue or impersonations.

## Generation procedure
1. Use Custom lyrics mode and paste lyrics/holos-intro-v1.txt.
2. Paste prompts/suno-style-v1.txt into the style field.
3. Paste prompts/suno-exclude-v1.txt into Exclude if available.
4. Target 50–60 seconds if duration controls allow. If the service cannot honour a five-second intro, generate a candidate and edit/crop the opening later.
5. Generate only within the account's currently available plan and credits. Do not upgrade, buy credits or authorize paid generation without Khaled's explicit approval.
6. Preserve all candidate IDs and original exports.
7. Evaluate opening transition, hook, intelligibility, vocal tone, syllable fit, ending and duration. Do not select a take solely because its style description looks right.
8. If no candidate meets the brief, change one variable at a time and log each attempt.

## Performance
One male mid-low lead, minimal vibrato, no screaming, clear diction. Pronounce HOLOS as “HOH-loss”. The final “Look between” is an anonymous processed texture, not an in-character line.

## Delivery
Preserve untouched original audio. Store edited audio separately. Handoff should include source candidate, approved WAV if available, review copy, lyric and prompt versions, candidate IDs, generation log, rights provenance and final approval. Do not spend credits or upgrade for stems.

## Acceptance
- [ ] Five-second instrumental cinematic opening.
- [ ] Clear hard cut into quirky alternative rock.
- [ ] Catchy, singable hook.
- [ ] Male mid-low vocal, restrained and intelligible.
- [ ] No character impersonations or separate dialogue.
- [ ] Lyrics fit canonical show and avoid unsupported scientific claims.
- [ ] Intentional clean ending.
- [ ] Reviewed against actual animation.
- [ ] Rights and provenance documented.
