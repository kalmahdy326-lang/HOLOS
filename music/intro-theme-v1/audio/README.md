# Audio delivery

No audio master is included in this source package yet.

Preserve untouched original generated or recorded audio. Store edited audio separately; never overwrite source. Preferred production master is uncompressed PCM WAV using the episode's approved sample rate and bit depth. Include an MP3/AAC review copy. Retain stems only if already available without unauthorized paid credits.

After delivery, record exact duration, sample rate, bit depth, channel count, loudness measurements and SHA-256.

Create a generation log recording date, tool/model/version, plan, prompt and lyric versions, candidate IDs, output filenames and hashes, rights basis, credits spent, selection rationale, reviewer and approval date.

Do not upload an audio file as an approved master until Khaled reviews it. Do not spend paid credits or upgrade without explicit authorization.
